# Data structures
### Queue
``` python
from collections import deque

queue = deque([])
queue.append(1)  # append to the right end
queue.appendleft(0)  # append to the left end
item = queue.pop()  # pop from the right end
item = queue.popleft()  # pop from the left end
```
### Priority Queue / Heap

``` python
import heapq
min_heap = []
heapq.heappush(min_heap, 5)
heapq.heappush(min_heap, 2)
smallest = heapq.heappop(min_heap)  # smallest will be 2
```
